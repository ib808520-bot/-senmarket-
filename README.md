# SENMARKET PRO
Marketplace full-stack de démonstration.

## Installation
1. Installer Node.js.
2. Dans ce dossier: `npm install`
3. Lancer: `npm start`
4. Ouvrir `http://localhost:3000`

## Inclus
- frontend responsive
- API Express
- base SQLite
- inscription/connexion avec hash de mot de passe
- JWT
- produits
- panier côté navigateur
- création de commande
- espace vendeur de base

## Pour production
Configurer un vrai secret JWT, HTTPS, validation stricte, stockage d'images, rôles vendeur/admin, paiement réel, livraison, emails/SMS, sauvegardes, monitoring et déploiement cloud. Ne jamais mettre de clés de paiement dans le frontend.
